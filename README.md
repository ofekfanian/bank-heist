# Bank Heist

GTA-style bank heist game built in Unity for the Game Development final project.

## Not included in this repo
- `Library/`, `Logs/`, `Temp/`, `UserSettings/` (Unity regenerates them on open)
- Recordings / videos
- Single asset files larger than 20 MB (Mixamo characters/animations `.fbx`, Volvo, jacaranda tree, etc.). Re-download them into the same folders under `Assets/`.
